## Overview
**LIFEOS – Intelligent Personal Resource Optimizer** is a Java-based
student decision-support system designed to help students manage their
**academic tasks, available study time, and personal budget** in an
organized manner.

The system combines task prioritization, smart study planning,
budget monitoring, and What-If financial analysis into a single
console-based application.

LIFEOS calculates task priority using factors such as **importance,
difficulty, estimated completion time, and remaining days**. Based on
the calculated priorities and available study hours, the system
generates a practical study plan.

The budget module calculates total expenses and remaining budget,
while the What-If Analyzer evaluates whether an additional expense
can be accommodated within the available budget.

The project demonstrates practical implementation of **Java,
Object-Oriented Programming, collections, exception handling,
sorting, modular programming, and decision-making logic**.

### Smart Study Plan

- Accepts available study hours.
- Sorts tasks according to priority.
- Allocates available hours to higher-priority tasks.
- Identifies tasks that can be completed.
- Marks tasks that should be postponed.
- Displays remaining available hours.

### Budget Management

- Maintains the student's monthly budget.
- Records expense categories and amounts.
- Calculates total expenses.
- Calculates remaining budget.
- Displays a clear financial summary.

### What-If Budget Analysis

- Accepts an additional expense amount.
- Calculates the budget after the additional expense.
- Determines whether the expense is affordable.
- Displays a warning when the budget is exceeded.

### Input Validation

- Validates task and expense values.
- Prevents negative expense amounts.
- Handles invalid menu selections.
- Uses Java exception-handling mechanisms where required.
