🚀 LIFEOS – Intelligent Personal Resource Optimizer

"Plan your tasks":- Manage your time. Control your budget. Make smarter decisions."**

LIFEOS is a Java-based student decision-support system designed to
bring **academic task management, study-time planning, and personal
budget management** together in one simple application.

🎯 1. Problem Statement
Students often have to handle multiple assignments, deadlines,
limited study hours, and daily expenses simultaneously.
When these activities are managed separately, students may face
questions such as:
- 📚 Which academic task should I complete first?
- ⏳ How should I use my limited study hours?
- 💰 How much of my monthly budget has already been spent?
- 📊 How much money is still available?
- 🤔 Can I afford an unexpected additional expense?
- ⚠️ Will a new expense exceed my available budget?
Traditional methods such as notebooks, separate to-do lists, and
manual calculations do not provide an integrated view of these
decisions.

💡 The LIFEOS Solution
LIFEOS addresses this problem by combining:
**Task Prioritization + Time Allocation + Budget Monitoring +
What-If Analysis**
into a single lightweight Java application.
Instead of only storing information, LIFEOS processes the available
information and provides **clear, decision-oriented results**.

🌍 2. Scope of the Project
The current scope of LIFEOS focuses on helping students manage their
basic **academic and financial resources** through a console-based
Java application.

📚 Academic Resource Management
- Manage academic task information.
- Store task importance and difficulty.
- Store estimated completion hours.
- Consider remaining days for deadlines.
- Calculate a priority score for each task.

⏰ Time Management
- Accept available study hours from the user.
- Sort tasks according to calculated priority.
- Generate a priority-based Smart Study Plan.
- Recommend tasks that can be completed.
- Identify tasks that should be postponed.

💰 Financial Resource Management
- Maintain a monthly student budget.
- Record expense categories and amounts.
- Calculate total expenses.
- Calculate the remaining budget.
- Display a clear budget summary.

🔮 Decision Support :-
- Perform What-If analysis for an additional expense.
- Calculate the budget after the additional expense.
- Determine whether the expense is affordable.
- Display a warning when the budget is exceeded.

The current version of LIFEOS does not include:
- 🗄️ Database or persistent data storage
- 🖥️ Graphical User Interface (GUI)
- ☁️ Cloud synchronization
- 👤 Multi-user authentication
- 🤖 AI/ML-based recommendations
- 📱 Mobile application
- 🔔 Notification and reminder services

⭐ 4. High-Level Features :-
Calculates the priority of academic tasks using factors such as:
Importance
Difficulty
Estimated completion hours
Remaining days
The calculated score helps determine which task should receive
higher priority.

⏰ 2. Smart Study Plan :-
The Smart Plan Generator uses:-
Task Priority + Available Study Hours
To create a practical study plan.
It identifies:
✅ Tasks that can be completed
⏸️ Tasks that should be postponed
⏱️ Remaining available study hours

💰 3. Budget Manager :-
The Budget Manager provides a simple way to monitor financial
resources.
It calculates:
Monthly Budget - Total Expenses = Remaining Budget

🔮 4. What-If Analyzer :-
The What-If Analyzer allows the user to test a possible additional
expense before making a decision.
The system then displays whether:
✅ The expense is affordable
⚠️ The budget would be exceeded

🛡️ 5. Input Validation :-
LIFEOS performs basic validation to improve reliability.
Examples include:
Preventing negative expense values
Checking important input values
Handling invalid menu selections
Using Java exception-handling mechanisms where required
